# IFSP Java Exercises

This repository is a collection of Java exercises developed during the Programming course at IFSP (Instituto Federal de São Paulo).  
The goal of this repository is to document my learning process and practical experience with core programming concepts in Java.

## 📚 What You'll Find Here

The exercises are organized by practice sessions, each corresponding to different class dates or topics covered throughout the semester.

### 🔹 Topics Covered

- Basic syntax and control structures
- Loops (`for`, `while`, `do-while`)
- Object-oriented programming (OOP)
- Arrays and collections
- Recursion
- File handling
- Exception handling

## 📂 Folder Structure

Each folder corresponds to a practice session, named as `Drills 1`, `Drills 2`, etc.
